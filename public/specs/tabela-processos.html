Structure, column sets, row/action behavior, and token usage for all three published states of the component: Default, Administrativos, and Judiciais. Implementation rules are out of scope for this document.

Anatomy

All three variants share the same four structural regions, stacked vertically inside a single rounded, drop-shadowed container:

RegionContentsPresent in
ToolbarRow-count selector (Mostrar 10) on the left; column-visibility toggle (Exibir Colunas) on the rightDefault, Administrativos, Judiciais
Header rowBold, 12px column labels, uppercase in source copyDefault, Administrativos, Judiciais
Body rowsData rows with alternating background fillDefault, Administrativos, Judiciais
Pagination footerFirst/Previous/Next/Last controls + page indicator, conditionally rendered via a showPaginacao flagDefault, Administrativos, Judiciais
Container: border radius 8px, drop shadow 0px 4px 3px rgba(0,0,0,.10), 0px 2px 2px rgba(0,0,0,.06), background white, overflow clipped.

Pagination

Identical control set across all three variants: First page, Previous page, Next page, Last page (four square buttons) plus a page indicator reading Página [current] de [total]. Rendering of this footer is conditional (showPaginacao prop in the extracted source).
